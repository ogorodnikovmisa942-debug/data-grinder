## Requirements

### R1. Гибридный визуализатор Каркаса Знаний (Tree Mindmap + Obsidian Graph View)
- **Базовый вид (Древовидная схема):** Иерархическая компактная структура («ствол → ветви → развилки»). Показывает соподчинение (Ветвь власти → Инстанции → Составы суда). Позволяет студенту за 20–30 секунд сформировать целостный контекст темы перед разбором карточек.
- **Интерактивное 2D-облако (Obsidian Graph View):** Открывается по кнопке «Облако связей». Реализовано на Canvas 2D (force-graph, ~110 KB, standalone CDN), неоновый dark-стиль, физика узлов, частицы на ребрах, pinch-to-zoom на мобилках в Telegram WebApp, энергосбережение через cooldownTicks(90).

### R2. Генерация графа и структуры книги (Knowledge Graph Schema)
- Модель извлекает из книги семантический граф:
  - nodes: идентификаторы, названия, категория (орган, инстанция, условие, исключение, правовой статус), краткая суть (1 завершенное предложение).
  - edges: направленные смысловые связи («обжалуется в», «исключает применение», «разграничивается с», «подсудно»).
- Сохранение сгенерированного графа в базе данных на уровне темы/колоды для мгновенного повторного открытия.

### R3. Рефакторинг генератора карточек: Развилки, Контраст-пары и Фундаментальные классификации
- **Баланс фундаментальной классификации и отсева воды:**
  - Фундаментальные деления институтов и категорий (например, императивные vs диспозитивные предписания, виды умысла, стадии процесса, подсудность) — ОБЯЗАТЕЛЬНЫ, но формулируются строго по существу, через функциональный признак, без словарной воды и академического пустословия.
  - Категорически запрещены пустые, тривиальные и общебытовые определения («Что такое правосудие?», «Зачем юристу логика?», «Что такое диалог?»).
- **Запрет примитивных «Да/Нет»:** Исключить тривиальные бинарные тесты, создающие иллюзию знания без понимания связей.
- **Карточки-развилки (Decision Trees / Situational Vignettes):** Ситуационный кейс с конфликтом условий → ключевой развилочный вопрос квалификации/тактики → однозначный вердикт со статьей закона/клиническим протоколом.
- **Карточки контраст-пар (Contrast Pairs):** Разграничение 2 внешне похожих понятий через один решающий водораздельный критерий (Gold Standard Criterion).
- **Математика сжатия:** Книга 185 страниц дает не 305–600 определений, а 70–90 фундаментальных, глубоких карточек-связок.
